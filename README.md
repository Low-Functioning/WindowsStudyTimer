StudyTimerX ⏱️
A lightweight, distraction-free study timer for Windows based on Python.


StudyTimerX is a simple desktop countdown timer designed to help you stay focused during study sessions. It features a clean dark interface, a floating mini clock, completion alerts, and automatic study-time tracking.
No unnecessary complexity. Just set your time and focus.


✨ Features
Countdown Timer – Set your preferred study duration.
Quick Presets – Choose from 5, 10, 20, 25, 30, 35, and 40 minutes.
Custom Duration – Set any duration from 1 to 1440 minutes.
Start / Pause / Resume – Easily control your study sessions.
Floating Mini Timer – Keep a compact timer visible while using other applications.
Always on Top – Display the floating timer above other windows.
Completion Alert – Get a popup notification and repeating alarm when your timer finishes.


🛠️ Built With
Python – Application logic
Tkinter – Desktop graphical interface
JSON – Local statistics storage
Windows API – Window management and DPI support
winsound – Alarm sound

🔰 Installation
Just Install Python 3.x & Tkinker download the .pyw file and double click on it.
